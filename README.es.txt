¿Actualizas desde la versión 1.1.x o anterior? Para activar las actualizaciones de estado instantáneas, cada termostato debe volver a unirse a la red: abre el dispositivo en Homey → ajustes → Mantenimiento → "Intentar reparar" y sigue las instrucciones (tus Flows se conservan). Si la reparación no ayuda, elimina el dispositivo y añádelo de nuevo.
