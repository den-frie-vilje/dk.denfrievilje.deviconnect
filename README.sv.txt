Hoppa över DEVIreg™ Connect-gatewayen och koppla dina DEVIreg ZigBee-enheter direkt med Homey. Håll enkelt koll på och styr dina termostater. Skapa Flows för att smidigt trigga din värmestyrning precis som du vill, tillsammans med dina smarta persienner eller gardiner, hemmabelysning och till och med ditt underhållningssystem.

Stöd för DEVIreg™-modeller: 
- DEVIreg™ Display Connect
- DEVIreg™ InControl

Uppgraderar du från version 1.1.x eller äldre? För att aktivera omedelbara statusuppdateringar måste varje termostat ansluta till nätverket igen: Öppna enheten i Homey → inställningar → Underhåll → "Försök reparera" och följ instruktionerna (dina Flows behålls). Om reparationen inte hjälper, ta bort enheten och lägg till den igen.
